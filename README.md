# 拾光 · Personal Growth RPG

一个本地优先的个人成长记录系统。它把每日打卡、成长日志、阶段任务和技能进度放进同一套游戏化模型中。

## MVP 功能

- 角色面板：等级、阶段、经验值、连续记录和近 7 天状态
- 每日打卡：生活习惯、能量、心情、睡眠与一句话记录
- 成长日志：记录事件、事实和复盘洞察
- 任务系统：按阶段自动解锁任务并计算奖励
- 技能树：职业、输出、学习、身体、生活和关系六条成长线
- 本地数据：使用 IndexedDB 保存，并支持 JSON 导出备份

## 目录

```text
src/
├── config/        # JSON 配置：习惯、任务、技能、阶段
├── lib/db.ts      # IndexedDB 数据访问层
├── App.vue        # MVP 页面与交互
├── types.ts       # 核心数据模型
└── style.css      # 响应式视觉样式
```

## 运行

```bash
npm install
npm run dev
```

数据只保存在当前浏览器设备。清除浏览器站点数据会删除记录，请定期使用页面左下角的“导出成长数据”。
